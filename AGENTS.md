- Finance maths lives only in src/lib/finance as pure functions; project() and monteCarlo() both use engine.simulatePath so they always agree.
- Currency conversion goes through fx.convert with USD-based rates (fx_rates table + profile.fx_overrides); a missing rate converts to 0 and is warned, never guessed.
- Money columns stay Postgres `numeric` (exact decimals); money.ts handles minor units and outputs are rounded with roundMoney.

## Working together (Lovable and other coding agents)

This repo is edited both in Lovable (straight to `main`) and by other agents through pull requests. To avoid conflicts and broken builds:

- **Keep `main` green.** CI (`.github/workflows/ci.yml`) runs `bun run typecheck`, `bun run test` and `bun run build` on every pull request and every push to `main`. Fix a red run before building more on top of it.
- **Generated files are never edited by hand:** `src/integrations/supabase/types.ts` (regenerated from the database; after adding tables via a migration, regenerate rather than hand-writing types, or the definitions get duplicated), `src/routeTree.gen.ts` (regenerated by the router plugin), and `src/integrations/supabase/client.ts`.
- **Database changes go in a new numbered migration** in `drizzle/migrations/` plus a journal entry; never edit an applied migration.
- **Check open pull requests before large edits.** If one touches the same files (e.g. `src/routes/index.tsx`, `src/components/AppShell.tsx`, `src/routes/spending.tsx`), merge it first or keep your change small, so the other side doesn't hit conflicts.
- **Branches merge `main` in before they're pushed**, so conflicts are solved on the branch, never on `main`.
- **Small, focused commits** with a clear message beat one large "Changes" commit; they're easier to merge and to revert.
- Features that already exist (check before adding a duplicate): quick add, setup checklist, budgets, sinking funds, safe-to-spend, Today card, health score (`healthReport`), net worth history, what-if scenarios, bills hub, guided check-in (`/check-in`), demo mode (`src/lib/demo.ts`), privacy mode, app lock, live market assumptions, Invest page.
